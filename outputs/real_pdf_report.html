PROJECT VISION

AI-Powered University Research Assessment Pipeline

From Raw Annual Reports to Validated Institutional Knowledge Graphs

01 Goal

02 Core Idea

Convert unstructured university annual reports into structured, validated, machine- readable research assessment profiles.

Parse, filter, semantically structure, extract, validate, and generate final institutional profiles.

01 Project Vision

CODATA OT-ViRARe

03 Final Output

JSON / knowledge graph profile containing grants, publications, faculty activity, collaborations, patents, open science indicators, outreach, and ranking metrics.

PDF → Blocks → HTML → AI JSON → Validation → Knowledge Graph

PROBLEM

Why This Pipeline Is Needed

Unstructured reports need deterministic preparation before AI extraction.

A Report Problems

B Direct LLM Problems

  • Long PDFs
  • Multi-column layout
  • Tables, headings, lists, faculty names
  • Inconsistent formats
  • Not machine-readable
  • Token overflow
  • Missed data
  • Hallucination
  • Department mixing
  • Expensive processing

02 Problem Statement

C Solution

Use a deterministic multi-stage pipeline where each stage produces a standardised output for the next stage.

The goal is not just extraction — the goal is traceable, validated, reusable institutional data.

TEAM PLAN

Balanced Team Work Separation

Difficult stages have support roles, and each folder has a clear owner.

Person Primary Ownership Support Role Complexity Folder Boundary

Person A Dossier, policy rules, metric definitions, JSON schema Filtering rules and validation review Medium–High /schema/, /docs/policy/

Person B PDF parsing, layout block extraction, token filtering Source traceability for validation High /src/parser/, /src/filter/

Person C HTML semantification, section structure, table reconstruction LLM chunk boundaries Medium–High /src/semantifier/

Person D LLM extraction, API wrapper, entity linking, validation Schema testing with Person A High /src/ai_agent/, /src/validator/

No one edits another person’s folder without review. Difficult stages have support roles to balance the team.
